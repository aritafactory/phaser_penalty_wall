# Color Block Breaker — техническое задание

## 1. Общее описание игры

**Суть проекта:** казуальная single-screen puzzle game, где игрок очищает стену из цветных блоков, стреляя шарами заданного цвета.

- Основной цикл: совпадение цвета → удаление связной области → вертикальная гравитация → выполнение условий уровня.
- На поле есть стена из блоков.
- Игрок стреляет шарами по целям того же цвета.
- После удаления группы блоки сверху падают вниз.
- Если в уровне несколько слоёв, после очистки первого слоя загружается следующий.
- Есть встроенные уровни, магазин бустеров, редактор уровней и поддержка пользовательских JSON-уровней.

## 2. Игровой цикл

1. Игрок выбирает уровень в меню.
2. Сцена строит поле из `grid` или `layer1..layerN`.
3. Перед стартом цвета разрушаемых блоков могут перемешиваться, специальные свойства блоков сохраняются.
4. Игрок выбирает цвет следующего шара из доступных цветов разрушаемых блоков на поле.
5. При совпадении удаляется связная область, затем срабатывает вертикальная гравитация.
6. За каждый удалённый блок начисляется **10 очков**.
7. Если очищен весь слой — загружается следующий слой или завершается уровень.
8. При активных ограничениях возможно поражение по таймеру или по числу выстрелов.

## 3. Базовые механики

### 3.1. Удаление групп

- Используется 4-связность (соседи сверху, снизу, слева и справа).
- Удаляется вся связная область совпадающего цвета.
- Новые блоки сверху не добавляются, остаётся только падение вниз.

### 3.2. Победа и поражение

- Победа: после удаления всех разрушаемых блоков на последнем слое.
- Поражение: по окончании `timerSeconds` или при исчерпании `maxShots`.
- После победы игрок переходит к следующему уровню, после поражения перезапускает текущий.

### 3.3. Очки и экономика

- Очки хранятся в `localStorage`.
- Очки тратятся на бустеры в магазине.
- Инвентарь бустеров также хранится в `localStorage` и переносится между уровнями.

## 4. Типы блоков

В коде поле кодируется строками:

- `R/G/B` — базовые цвета;
- `Y/P/O` — дополнительные;
- `U` — неразрушаемый блок;
- `F` — flashing-блок;
- префикс `M` — moving;
- префикс `2` — special `2Colors` / multi-hit кодирование.

| Тип | Код | Поведение |
|---|---|---|
| Обычный цветной блок | `R`, `G`, `B` | Удаляется, если входит в связную область совпадающего цвета. |
| Дополнительный цветной блок | `Y`, `P`, `O` | Работает как обычный блок, но доступен только на уровнях с `Additional colors`. |
| Неразрушаемый блок | `U` | Не удаляется обычным выстрелом; в текущем коде может быть убран `Bomb`. |
| Мигающий блок | `F` | Циклически меняет цвет между двумя состояниями примерно раз в `800 ms`. |
| `2Colors` блок | `2R`, `2G`, ... | В текущем коде трактуется как `strength=2`, но в ТЗ должен описываться как перекрашиваемый special-блок. |

## 5. Усложнения уровня

| Усложнение | Как задаётся | Игровой эффект |
|---|---|---|
| Additional colors | `complications + Y/P/O` | Добавляет дополнительные цвета в палитру уровня. |
| Timer | `timerSeconds` | Ограничивает время прохождения. |
| Limited shots / Tries | `maxShots` | Ограничивает число выстрелов. |
| Unbreakable blocks | `U` в `grid` | Создаёт препятствия, разрывающие кластеры. |
| 2 colors blocks | `2X` | Добавляет special-блоки с отдельной логикой. |
| Flashing colors blocks | `F` | Блоки меняют цвет во времени. |
| Several layers of wall | `layers + layerN` | После очистки слоя загружается следующий. |

## 6. Бустеры

В основном режиме бустеры покупаются за очки. В редакторе уровней стартовые бустеры можно задавать прямо в JSON.

| Бустер | Цена (очки) | Эффект |
|---|---:|---|
| Mix | 100 | Перемешивает текущие цвета разрушаемых немигающих блоков, не меняя тип клетки. |
| Rotator | 120 | Поворачивает внешнее кольцо выбранной области 3×3 по часовой стрелке. |
| Compressor | 140 | Сдвигает блоки каждой строки к центру. |
| +5 shots | 160 | Добавляет пять выстрелов, если уровень использует `maxShots`. |
| +10 seconds | 160 | Добавляет десять секунд, если уровень использует таймер. |
| Bomb | 180 | Удаляет область 3×3 вокруг цели, включая special-блоки; в текущем коде может убирать и `U`. |
| Rainbow | 200 | Следующий выстрел игнорирует проверку совпадения цвета шара и цели; шар становится градиентно-радужным. |
| Fractions | 240 | Убирает целевой кластер и до двух случайных кластеров того же цвета. |
| -1 color | 280 | Удаляет все блоки наименее представленного цвета среди разрушаемых. |

## 7. Уровни и формат данных

- Встроенные уровни описаны в `levels.js`.
- Пользовательские уровни лежат в JSON.
- Типовая структура уровня: `level`, `description`, `complications`, `grid` либо `layers + layerN`, `boosters`, а также опционально `timerSeconds`, `maxShots`, `movingRows`.

| Поле | Тип | Назначение |
|---|---|---|
| `level` | `number` | Номер уровня |
| `description` | `string` | Описание / служебная подпись |
| `complications` | `array[string]` | Список активных усложнений |
| `grid` | `string[][]` | Сетка однослойного уровня |
| `layers` | `number` | Количество слоёв |
| `layer1..layerN` | `string[][]` | Сетки отдельных слоёв |
| `timerSeconds` | `number` | Лимит времени |
| `maxShots` | `number` | Лимит выстрелов |
| `boosters` | `object` | Стартовые количества бустеров |

## 8. Редактор уровней и пользовательский контент

- Редактор позволяет менять размер сетки, вручную заполнять коды и сразу смотреть Phaser-preview.
- Можно включать усложнения, задавать `timerSeconds`, `maxShots`, число слоёв и стартовые бустеры.
- Редактор сохраняет уровень в JSON и загружает JSON обратно в форму.
- Для доступа к папке игры используется File System Access API; handle к папке сохраняется через IndexedDB.
- Экран уровней показывает основные уровни из `levels/manifest.json` и мастер-уровни из `levels/master_levels/manifest.json`.
- Кастомные уровни добавляются в общий список и визуально помечаются как пользовательские.

## 9. Важное замечание по механике `2Colors`

1. Если цвет шара совпал с областью попадания, удаляются обычные блоки соответствующего цвета в связной области.
2. `2Colors`-блоки того же цвета в этой области **не удаляются**.
3. Каждый такой `2Colors`-блок перекрашивается ровно один раз в случайный новый цвет, не равный предыдущему.
4. В рамках того же выстрела не должно быть повторных проверок, повторных перекрасок и дополнительных цепочек.
5. Следующий выстрел уже работает по новому состоянию поля.

## 10. Встроенные уровни

- Первые 7 уровней — по одному усложнению на уровень.
- Следующие 7 уровней сочетают по 2 усложнения.
- Следующие 7 уровней — по 3 усложнения.
