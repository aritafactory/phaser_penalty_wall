# Color Block Breaker (Phaser HTML)

Минимальная HTML-версия игры на Phaser по вашему ТЗ.

## Быстрый запуск

> Нужен любой локальный HTTP-сервер (нельзя открывать `index.html` через `file://` из-за ограничений браузера).

### Вариант 1: Python

```bash
python -m http.server 8080
```

Откройте в браузере: <http://localhost:8080>

Основная игра: <http://localhost:8080/index.html>  
Отдельный конструктор уровней: <http://localhost:8080/builder.html>

### Вариант 2: Node.js

```bash
npx serve .
```

Если браузер показывает старый UI, сделайте hard refresh (`Ctrl+F5` / `Cmd+Shift+R`).

## Что реализовано

- Phaser 3 через CDN.
- Выбор уровня и запуск.
- Отдельная страница `builder.html` с `Level Builder`: выбор размеров сетки, ручная раскладка ячеек, включение усложнений, preview, экспорт/импорт JSON.
- 23 встроенных уровня по обновлённому правилу: 7 уровней с 1 усложнением, 8 — с 2, 8 — с 3.
- Игровое поле в стиле референса: крупные квадратные блоки в верхней части и шутер-шар внизу по центру.
- При каждом старте уровня раскладка (позиции и цвета разрушаемых блоков) перемешивается случайно.
- Цвет следующего шара выбирается автоматически случайно (не повторяет предыдущий), без ручного выбора пользователем.
- Удаление связной области (4-связность).
- Вертикальная гравитация после удаления.
- Анимация полёта шарика к цели, анимация попадания и анимированное опадание блоков вниз.
- `U` как неразрушаемый блок.
- `maxShots` и `timerSeconds` как условия поражения.
- `2Colors`: участвует в цветовой связности области выстрела, сам не удаляется в этом выстреле, но перекрашивается и становится обычным блоком нового цвета.
- `Flashing blocks`: мигающие блоки меняют цвет каждые ~800ms, причём оба цвета берутся из палитры текущего уровня (без `additional_colors` — только базовые, с `additional_colors` — расширенная палитра).
- `Several layers`: уровень может содержать 2 слоя, второй загружается после полной очистки первого.
- Накопительные очки сохраняются в `localStorage` и переносятся между запусками.
- Кнопка `Shop` открывает поп-ап магазина бустеров (Bomb, Mix, Fractions, -1 color, +5 shots, Rainbow) с покупкой за очки.
- Купленные бустеры отображаются в правой панели `Bought boosters` с текущим количеством.
- В правой панели кнопка `Use` у строки `Bomb` активирует бустер: следующий клик по полю удаляет область 3×3 независимо от цвета и типа блока (включая `U`, `2Colors`, `Flashing`).
- В правой панели кнопка `Use` у строки `Mix` активирует бустер: следующий клик по полю случайно меняет цвета всех блоков, кроме `U`.
- В правой панели кнопка `Use` у строки `Fractions` активирует бустер: следующий клик удаляет целевой кластер и до двух случайных дополнительных кластеров того же цвета.
- В правой панели кнопка `Use` у строки `-1 color` активирует бустер: выбирается случайный цвет, все обычные/flashing блоки этого цвета удаляются, `2Colors` этого цвета становятся обычными блоками другого цвета, `U` не затрагиваются.
- В правой панели кнопка `Use` у строки `+5 shots` активирует бустер: на уровнях с `limited shots` добавляет +5 к текущему лимиту выстрелов.
- В правой панели кнопка `Use` у строки `Rainbow` активирует бустер: следующий выстрел игнорирует проверку совпадения цвета и летит как цвет блока цели.

## Текущее ограничение

Это MVP-реализация: в геймплей подключены `Bomb`, `Mix`, `Fractions`, `-1 color`, `+5 shots` и `Rainbow`.
